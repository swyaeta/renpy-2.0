# ganjichudail aur birju

A 2D mystery visual novel built with the Ren'Py engine.

## Story

A dramatic Ren'Py visual novel about Ganji Chudail, whose husband Birju is cheating on her with her sister Kapali Chudail and tries to run away with her money but he doesnt know the truth. Make wise choice

## Built With

- Ren'Py Visual Novel Engine

## How to Run Locally

1. Download and install Ren'Py from renpy.org
2. Clone or download this repository
3. Open the project in Ren'Py launcher
4. Click Play!
